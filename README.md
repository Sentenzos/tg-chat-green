# Telegram Chat + GREEN-API

Вход по данным инстанса GREEN-API.

В приложении можно:

- войти по `idInstance` и `apiTokenInstance`;
- добавить контакт по номеру телефона;
- отправлять и получать текстовые сообщения.

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run lint
npm run build
```
